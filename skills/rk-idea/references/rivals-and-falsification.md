# Rivals and falsification

Use this to build the rival set, the prediction, the cheapest discriminating check, and the result that would weaken the candidate. A matching pattern later does not make the survivor true. Unknown and mixed accounts stay open.

## Build the rival set first

Before settling on a check, list accounts that could produce the same appearance. Use a class only when it is plausible in this system:

- the proposed mechanism
- a simpler model or an already available method
- a measurement or processing artifact
- an implementation fault or a mismatched baseline
- a common cause of the exposure and the outcome
- selection, attrition, or restriction to who remains observable
- conditioning on a common effect of two causes
- the outcome, or its precursor, influencing the exposure
- a different regime, time, or context
- chance variation

Write the rival rows before expanding them from the favorite story, so the first account does not set the whole list. Do not force a fixed count or pretend the accounts are mutually exclusive. A mixed explanation is allowed. Every row stays a candidate.

## What each prediction contains

For every candidate that might be pursued:

- parent candidate
- conditions and boundary regime
- observable and measurement
- pattern expected if this candidate holds
- pattern expected if a named rival holds
- result incompatible with this candidate when the assumptions hold
- indeterminate result, and what remains open if it occurs
- uncertainty, including whether the gap between patterns exceeds the expected measurement error

Write this before using the target result. A pattern noticed after seeing that result is exploratory. It can motivate a later check. It cannot fill the confirmatory row.

Leave magnitude blank when it is unknown. Direction, a smallest difference that would matter, or a justified range is enough.

## Cheapest discriminating check

Pick the cheapest comparison, measurement, or proof obligation on which the focal candidate and a live rival disagree by more than the expected uncertainty.

Prefer that check over a larger effort that would look the same under both accounts. If the disagreement is smaller than the uncertainty, the check is indeterminate: reframe it, or defer until a measurement can resolve the gap.

For a formal claim, the check is the proof obligation or a counterexample. A performance table does not replace it.

State the conditions that make the check interpretable:

- the manipulation or assignment happened as declared
- the measurement can resolve the predicted gap
- the rival's path is actually closed by the comparison
- missingness and alignment would not by themselves create the pattern

Record an assumption-failure check for each of those. Run that check in interpretation before calling a result incompatible.

## Controls that change the reading

Add a control only when its result would change the judgment.

A negative control is a case where the proposed mechanism cannot operate and the bias paths under study remain. Say which bias paths are shared and why the mechanism cannot act. A non-null control means those bias paths are still live. It does not prove the mechanism, and a null control does not certify that bias is absent. An untreated group the mechanism could still affect is not a negative control.

A positive or procedural control shows that the measurement can recover a change already known to be present. If it fails, defer: the scientific check is uninterpretable until measurement performance is restored.

## Null model

A null is a stated no-difference claim for a named contrast. It is not a slogan that nothing happened. Say how compatibility will be read, and say explicitly that failing to reject the null is not equivalence, not absence, and not a win for the rival. If equivalence is the scientific target, write the margin now.

## How a later result will be labeled

Leave these blank until a result exists. Then use one label:

- Consistent with the candidate: the focal pattern appeared, the rival pattern did not, the controls held, and the uncertainty still allows the predicted gap.
- Challenges the candidate: the incompatible result appeared while manipulation, measurement, and the declared assumptions remain credible.
- Supports neither, or a mix: both patterns, neither pattern, or a failed assumption or control.

A result consistent with the candidate does not retire rivals the check did not touch.

## Tie to the judgment

No check separates the live rivals: reframe or reject. A check exists, but an unprobed assumption would flip its meaning: defer and name the assumption-failure check. The check separates the live rivals and the weakening result is stated: the candidate may be pursued, still as a judgment.
