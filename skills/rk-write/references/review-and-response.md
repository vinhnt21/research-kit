# Review and response

Treat an unpublished manuscript and its review as confidential. Do not send confidential review text to an external service. Keep the work on the files the human authors have already authorized.

Authorship and submission stay with the human authors. A draft review or a draft reply is material for them to rewrite and send. This skill does not decide acceptance, contact an editor, or file the manuscript.

When a venue is in scope, that venue's review rules and response format win over the layout below.

## Classify the point

Restate the scientific point in fresh words. Then place it in one class, using the paper's notes, pages, and run outputs.

1. **Fatal flaw.** The central claim or the design fails if the point is correct, and no change of wording repairs it. Stop. Tell the human authors. Leave the claim's source empty until a real record exists.
2. **Fixable gap.** The design can stand once an existing page, table, or run is reported, corrected, or the sentence is narrowed. Name that page or run in the reply.
3. **Missing evidence.** The comment asks for a result, a count, or a protocol line that is not in the record. Say it is absent. Leave the claim blank.
4. **Style preference.** The science is unchanged. The point is wording, order, or taste. Edit when the change makes the message easier to see or the venue asks for that form. Name the page you changed.

Ask which class applies before editing. A missing methods detail is a fixable gap when the lab record already has it, and missing evidence when the record does not.

## Check before changing

Verify the point against this paper's notes and outputs.

- Match the comment to a page, figure, table, or run.
- See whether the suggestion fits this design. A change that would hide a null, invent a number, or relabel an exploratory result as confirmatory stays undone.
- If the comment conflicts with a prespecified plan, say so. A change to that plan is a deviation and the affected result becomes exploratory if the authors adopt it.
- Change one item at a time when the item would alter a reported result. A new analysis belongs outside this skill. The reply may say that the analysis has not been run.

Agree or refuse only after that check. If the point is wrong for this paper, the reply gives the page or run that shows why.

## Write the reply

For each comment, write four parts:

1. The point, restated.
2. The class: fatal flaw, fixable gap, missing evidence, or style preference.
3. The page, table, figure, or run that was checked. Quote no more of a confidential comment than the authors need in order to recognize it.
4. What changed, or why the text stands, within that evidence.

Do not promise an unrun experiment. A future experiment stays a plan the human authors may or may not do. Do not describe it as finished, and do not invent a result for it.

Do not invent agreement among reviewers. Map claims that the reply adds or narrows with [claim-evidence.md](claim-evidence.md). An empty source stays in the list returned with the draft.
