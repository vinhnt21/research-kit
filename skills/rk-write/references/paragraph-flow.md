# Paragraph flow

One paragraph carries one message. That message is the first sentence. After the paragraphs exist, build a reverse outline and keep only the paragraphs that map.

When a venue is in scope, its instructions on headings, paragraph length, and section order win over this test.

## Paragraph test

Read the paragraph as a reader who has not seen the author's notes.

1. Mark the message. A second result, a new contrast, or a limitation that starts its own argument belongs in another paragraph.
2. Read the first sentence alone. It should state the message. A first sentence that only names a topic fails the test.
3. Read each later sentence. It should give the reason, the detail, or the evidence for that same message. In the margin, name the link to the sentence before it: cause, contrast, consequence, refinement, or example. A sentence with no such link is a cut or a new paragraph.
4. Check the nouns. A term the reader needs is defined in this paragraph or in an earlier paragraph this one points to. Use one term for one concept across the section.

Revise the first sentence before adding connective phrases. Fluent wording does not replace a missing message.

## Reverse outline

Do this after the paragraph test, from the draft on the page.

1. Write one sentence for the section's job, using [section-roles.md](section-roles.md) and the venue's instructions when a venue is in scope.
2. List the first sentence of each paragraph, in order. Use those sentences as written.
3. Under each first sentence, list the evidence or explanation the paragraph actually contains. Add nothing that is not on the page.
4. Keep the paragraph only when its first sentence serves the section sentence and every later sentence serves that first sentence.
5. If the first sentences are hard to list, they are unclear. Rewrite them, then repeat the outline.
6. Temporary headings may expose the outline while you revise. Remove a heading the venue does not use.

Cut or split a paragraph that does not map. Report any claim in the surviving paragraphs whose source is still empty, using [claim-evidence.md](claim-evidence.md).
