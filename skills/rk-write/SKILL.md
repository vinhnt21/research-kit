# Draft or revise the paper

Draft or revise publication prose so each section, paragraph, and reviewer reply stays tied to evidence already in hand. A progress report or a talk belongs to `rk-report`. A literature search and an analysis run are outside this skill.

## Active paper

Resolve the paper from the request, the working directory, or that project's own instructions, such as an `AGENTS.md` beside the work. Read that paper's scientific notes before changing its files or stating its results. If several papers fit and the task would write, run, or make a paper-specific claim, ask which paper applies.

Leave sibling papers untouched. A sibling draft, bibliography, figure, codebase, or unpublished result is not a citation, a baseline, or reusable text. A shared read-only literature collection may be consulted after each source is checked for this paper. Put new files where this paper already stores that kind of artifact. Do not impose a directory layout, venue name, or tool.

One substantive claim needs one source. Abstract and conclusion may not outrun results. One message per paragraph, stated first, then a reverse outline. Separate fatal flaw, fixable gap, missing evidence, and style preference. Do not promise an unrun experiment. Authorship and submission stay with human authors. Do not send confidential review text to an external service.

## Procedure

Read the paper's scientific notes before editing its files or stating a result. When a venue is in scope, read that venue's current instructions as well. Those instructions win over this skill's section guide. IMRaD is optional.

Open one reference for the branch you are in.

1. Listing or checking claims: follow [references/claim-evidence.md](references/claim-evidence.md) and the blank rows in [assets/claim-evidence.md](assets/claim-evidence.md). Leave the source empty when it has not been opened.
2. Drafting or revising one section: follow [references/section-roles.md](references/section-roles.md) for that section's job. Skip the other section jobs until their text is the task.
3. Testing whether paragraphs carry: follow [references/paragraph-flow.md](references/paragraph-flow.md) after the prose exists.
4. Reviewing a manuscript or answering a reviewer: follow [references/review-and-response.md](references/review-and-response.md).

A figure or table is optional. Include one only when it shows a verified result more clearly than a sentence, and keep its values aligned with the prose.

## Return

Return the requested draft or revision. With it, list every substantive claim whose source is still empty. Name the authorship, disclosure, ethics, and submission decisions that remain with the human authors.
