# Report a verified result

Brief a collaborator only after the headline number can be regenerated from this paper's own outputs. Progress notes, result briefings, and research talks stay here. Manuscript prose, including a results section, belongs to `rk-write`. This skill does not invent a result, search the literature, or submit itself to a venue.

## Active paper

Resolve the paper from the request, the working directory, or that project's own instructions, such as an `AGENTS.md` beside the work. Read that paper's scientific notes before changing its files or stating its results. If several papers fit and the task would write, run, or make a paper-specific claim, ask which paper applies.

Leave sibling papers untouched. A sibling draft, bibliography, figure, codebase, or unpublished result is not a citation, a baseline, or reusable text. A shared read-only literature collection may be consulted after each source is checked for this paper. Put new files where this paper already stores that kind of artifact. Do not impose a directory layout, venue name, or tool.

Order: regenerate the headline number, label exploratory versus confirmatory, then record local paths for code, data, environment, and protocol. Confirmatory means the result matches a freeze made before the outcome was seen. Sharing is a human action.

Lead with question, evidence scope, decision, and uncertainty. One claim per talk segment. Label simulation versus experiment.

## Procedure

1. Resolve the active paper and read its scientific notes before stating a result.
2. Follow [the report gate](references/report-gate.md). Stop on any headline number the gate cannot regenerate. Keep the exploratory label when a freeze does not exist.
3. Fill [the report record](assets/report-record.md) where this paper already stores notes or talks. The archive list is local paths for code, data, environment, and protocol. Leave a missing path blank.
4. Write the briefing from that record. Sharing it is a human action outside this skill.

## Briefing

Open with four items, in this order:

1. Question the work addressed.
2. Evidence scope: what was measured, on which material, and what was left out.
3. Decision the evidence supports.
4. Uncertainty, including a negative or indeterminate outcome that changes the decision.

State only numbers the gate regenerated. If the outputs include an interval or other spread, report it with the point value. Do not replace a missing spread with a rounded impression.

For a talk, put one claim in each segment. Label that segment simulation or experiment. Keep units and uncertainty readable. A personal deck style may live in the paper; it is not part of this skill.

For a progress note, name the next verifiable step and what would count as done. A pilot stays a pilot.

## Return

Return the briefing or talk outline, the filled record, and any number that could not be regenerated. Name any venue, authorship, or sharing choice a person must make. Do not send the report onward.
