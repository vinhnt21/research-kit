# Survey prior work

## Active paper

Resolve the paper from the request, the working directory, or that project's own instructions, such as an `AGENTS.md` beside the work. Read that paper's scientific notes before changing its files or stating its results. If several papers fit and the task would write, run, or make a paper-specific claim, ask which paper applies.

Leave sibling papers untouched. A sibling draft, bibliography, figure, codebase, or unpublished result is not a citation, a baseline, or reusable text. A shared read-only literature collection may be consulted after each source is checked for this paper. Put new files where this paper already stores that kind of artifact. Do not impose a directory layout, venue name, or tool.

## Working language

These instructions stay in English. The reply does not.

Write the chat reply, questions, and internal notes in the language the user is writing in. If this paper already keeps those notes in one language, continue in that language. If the request has no clear language, or the user's language and those notes disagree, ask which language to use before writing the note.

Write that language as an original note to a colleague. Do not translate these instructions sentence by sentence. Keep this skill's field names, and terms this paper already uses, as they already appear. In Vietnamese, use a short sentence a lab mate would say, and leave a research term in English when the Vietnamese word would be unclear or mean something else. For example, write "Số này lấy từ file vừa mở lại. Chưa kết luận nguyên nhân." Do not write "Bản ghi này bảo đảm tính liêm chính của đầu ra đã được mở lại."

A manuscript, a figure label, and a slide use the language of that artifact. If the task would write the artifact and that language is not already clear, ask before drafting it.

## Scope

Use this skill to bound a search, check the sources you will rely on, and write an evidence map or gap statement for the active paper. Idea critique before a search, method choice, data analysis, and manuscript prose are other skills. Stop at the map.

A convenient search is a literature map. Call it a systematic review only when a protocol was followed and the search record shows that protocol, including the inclusion rule and the stop rule.

## Procedure

1. Bound the search before screening. Follow [Search boundary](references/search-boundary.md). Copy [Search record](assets/search-record.md) into the place this paper already keeps literature notes, then fill every field. Record the query, the access date, the inclusion rule, and the stop rule.
2. Check each source that will support a claim, a baseline, or a gap. Follow [Citation check](references/citation-check.md) and complete one [Citation checklist](assets/citation-checklist.md) per source. Record the identifier, the version, the venue, whether you opened the full text or only an abstract, and the retraction or correction status.
3. Synthesize only sources that passed that check. Follow [Evidence map](references/evidence-map.md). Group by design and outcome. Keep a reported result apart from speculation and from a later paraphrase.

## Limits you must keep

Write "Not found in this search" when the recorded queries and stop rule did not surface a topic. That sentence is not "never studied." Name the nearest work the search did find, or say that no included work was near.

Do not invent a citation. A suggested reference stays unchecked until its identifier opens on the work you mean. If you saw only an abstract or a snippet, the map says so, and numeric or methodological claims stay inside that text.

Return the filled search record, the citation checks for load-bearing sources, and the evidence map. Use this paper's bibliography style when it already has one.
